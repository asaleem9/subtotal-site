# subtotal-site

The marketing site for [Subtotal](https://github.com/asaleem9/subtotal), a free iOS subscription
tracker. One long receipt: the page prints top to bottom, a running tape in the margin adds up
line items as you scroll, and at the peak you build your own ledger from the app's real catalog.

Static HTML, no framework. Scroll choreography runs on the scroll-craft engine (`engine/`,
copied verbatim, never edited), bespoke motion on GSAP (`vendor/`), and the product clip is a
HyperFrames composition (`video/`) rendered to MP4 and re-encoded with a dense GOP for scrubbing.

## Run it

```sh
npm install
npm run sync      # pulls poses, screenshots, logos and the slim catalog from ../sub-manager
npm run serve     # http://localhost:4500
```

Deploys to Vercel from the repo root (`vercel --prod`). `vercel.json` sets clean URLs and
immutable caching for `/assets`, `/vendor`, `/fonts`, `/engine`.

## Layout

- `index.html`, `privacy/`, `support/`: the three pages. `css/site.css` holds the tokens.
- `js/`: `tape.js` (the running receipt), `catalog-search.js` and `ledger-math.js` (ports of the
  app's Swift), `picker.js`, `hero.js`, `tiles.js`, `site-config.js` (App Store URL, support email).
- `data/catalog.json`: 587 services, generated by `scripts/sync-assets.mjs`.
- `video/add-flow`, `video/add-flow-portrait`: HyperFrames projects for the scrub clip.
- `design/`: the Octo manifest and `scripts/gen-mascots.py`, which drives the Codex CLI's image
  tool for new poses. Copy the app's `octo-hero.png` into the output folder first; it is the
  style reference for every pose.
- `scrollcraft/`: BRIEF.md, FINGERPRINTS.md and the contact sheets from verification.

## Logos

Brand glyphs are Simple Icons (CC0). The other icons are the services' own app icons, shown only
to identify the service you subscribe to. All trademarks belong to their owners. Deleting a file
from `assets/logos/` makes that service fall back to a monogram tile.
